## 2. 动作分级

> 按**改动的可逆性与影响面**分级，**不按改动规模**。

| 等级 | 范围（路径面） | 策略 |

## 4. 决策血缘

每次 agent 会话落**一份**记录：`{{血缘目录}}/{{命名规则}}`。

### 4.1 必填字段

| 字段 | 含义 | 合规属性 |
|---|---|---|
| `run_id` | 全局唯一标识 | — |
| `started_at` / `ended_at` | UTC 时间戳 | *同步*——禁事后补录；补录须显式标记并说明原因 |
| `agent` | 角色 id（须在 §1 在册）+ 模型标识 | *可归属* |
| `goal` | 一句话目标陈述 | — |
| `action_level` | 本次触及的最高等级 | — |
| `files` | 触及文件路径数组 | *可追溯* |
| `declares` | 声明触及的 ID（须在 [`DECISIONS.md`](DECISIONS.md) 在册） | *准确*——与实际 diff 不符即"幻觉" |
| `gates` | 各闸门结果 | — |
| `human_release` | `L2` 必填：放行人 + 方式 + **被放行的改动集标识** | *可归属* |
| `iterations` | 迭代轮数 | 护栏判据 |
| `cost` | token / 计算分钟；**未知填空值而非 0** | *准确* |

### 4.2 硬要求

- **append-only**：只许新增。写错了 → 新增一条更正记录，**不改原件**。
- **失败与中止的会话同样落血缘**——只记成功会话是有偏采样。
- `files` 含 `L2` 路径面 → `human_release` 不得为空。

| id | 规矩 | 理由 |
|---|---|---|
| `AO-1` | **能用确定性规则表达的，禁止交给模型。** | 做成 agent = 把可验证约束换成不可验证约束，还丢掉可复现性 |

| `AO-3` | 治理只诊断、不自动改。校验器无 `--fix` | 自动修会让执行者跳过"为什么违规" |

## 附录：格式契约（校验器解析规则）

1. §1 能力注册表：首列为反引号包裹的角色 id；至少一行。
2. §2 动作分级：首列为反引号包裹的四个等级，**四行齐全**；
   `L1`/`L2` 行的路径面 glob **必须能匹配到仓库中真实存在的路径**（防表格腐烂）。
3. §3 禁令：首列为反引号包裹的 `F-n`；每行须有"机器守护"列；
   **无守护的禁令必须在 §7 豁免在册**。
4. §4.1 必填字段表：血缘记录须含全部必填字段；`declares` 的 ID 须在册。
5. §5 护栏表首列非空；§6 硬规矩首列为反引号包裹的 `AO-n`。
6. **任一表解析为 0 行 = 格式契约破坏 = 红。**
