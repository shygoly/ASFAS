## 附录：格式契约（校验器解析规则）

1. §1 枚举表首列为反引号包裹的枚举名；取值列为方括号包裹的有序列表。
2. §2 起每个 `##` 小节为一个聚合；对象表首列为反引号包裹的对象名。
3. 文档对象名集合 **==** schema 对象名集合（双向，集合相等）。
4. 文档枚举名集合 **==** schema 枚举名集合；且逐枚举取值序列 **==** schema 取值序列（**顺序敏感**）。
5. 文档中出现的 `INV-n` / 决策 ID 必须在 `DECISIONS.md` 在册。
6. 文档中的相对路径链接目标必须存在。
7. **任一契约表解析为 0 行 = 格式契约破坏 = 红。**
